# Contract: ascope-live-data-orchestration-v1

Continue from the completed A-SCOPE software baseline into a reproducible live-data operating chain.

## In scope

- automatic trusted chaining from bulk security discovery to financial request batches;
- immutable GitHub Release intake for validated live bundles;
- automatic monthly screening after successful intake;
- local financial-batch merge and validated bundle packaging tools;
- step-by-step data-operator documentation.

## Out of scope

- fabricating missing market or financial data;
- committing large point-in-time datasets to normal Git history;
- automatic publication of research output;
- automatic trading, leverage, model execution or automatic merge.
