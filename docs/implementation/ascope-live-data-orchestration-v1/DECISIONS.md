# Decisions

1. Use GitHub Release assets as the manual large-data ingress boundary.
2. Automatically screen only after release intake validates the bundle.
3. Keep final research publication manual after human review.
4. Chain financial request generation only from successful same-repository non-PR discovery runs.
5. Preserve completed F10 batches and rerun only failed batches.
6. Do not use Eastmoney full-market pagination or per-security polling as the primary data path.
