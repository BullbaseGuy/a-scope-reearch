# A-SCOPE architecture

```text
CNInfo bulk security identity
→ point-in-time market and financial bundle
→ hard risk gates
→ ten-archetype routing
→ change, evidence, expectation and odds dimensions
→ research-priority shortlist
→ REOS-S handoff
```

The discovery layer never creates a buy signal. The REOS-S layer must still close P0 gaps, verify primary evidence, build scenarios, define invalidation dates and calculate risk budget.
